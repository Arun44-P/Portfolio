# Personal Portfolio Website

Personal portfolio website built using pure **HTML5** and **CSS3**.

## Features
- Semantic HTML5 elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`)
- Clean, responsive CSS3 layout (Flexbox & CSS Grid)
- Smooth scrolling and clean hover interactions
- Built without external frameworks or JavaScript
- Fully responsive across desktop, tablet, and mobile devices

## Built With
- HTML5
- CSS3
